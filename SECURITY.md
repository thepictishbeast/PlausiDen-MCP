# Security Policy

## Reporting Vulnerabilities

Report security vulnerabilities to **security@sacredvote.org**.

Expected response time: 48 hours for acknowledgment, 7 days for initial assessment.

## Scope

This policy covers the PlausiDen MCP server crate, including:
- Capability-based access control bypass
- Audit log tampering or hash chain forgery
- JSON-RPC injection or protocol-level attacks
- Resource limit bypass
- Unintended network access without Swarm capability

## Responsible Disclosure

We follow coordinated disclosure. Please allow 90 days for fixes before public disclosure.
